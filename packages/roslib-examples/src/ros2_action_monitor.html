ROS 2 Action Monitor

Observe status and feedback for goals sent by any client. Start rosbridge and a Fibonacci action server, connect below, then send a goal from a separate terminal or the ROS 2 Action Client example. 

ros2 launch rosbridge_server rosbridge_websocket_launch.xml
ros2 run action_tutorials_py fibonacci_action_server
ros2 action send_goal /fibonacci action_tutorials_interfaces/action/Fibonacci '{order: 10}' --feedback

This page only subscribes; it does not send or cancel goals. QoS overrides require rosbridge protocol 2.1.0 or newer. The status subscription requests the latest snapshot so it can also observe goals that are already running.

These commands use the Humble/Jazzy tutorial interface. If your tutorial server uses example_interfaces/action/Fibonacci, select that action type below and use it in the goal command as well.
